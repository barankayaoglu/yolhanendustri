Site paneli

Sitedeki yazıları, fotoğrafları, markaları ve ürün gruplarını buradan değiştirip yayınlayabilirsiniz.

Erişim anahtarını nasıl alırım? (bir kez yapılır)
  1. GitHub'da yeni anahtar sayfasını açın ve GitHub hesabınızla giriş yapın.
  2. Token name alanına “Site paneli” yazın. Expiration için en uzun süreyi seçin.
  3. Repository access bölümünde Only select repositories seçip yolhanendustri deposunu işaretleyin.
  4. Permissions bölümünde + Add permissions'a basıp Contents'i seçin ve erişimini Read and write yapın. Yine + Add permissions ile Actions'ı ekleyip Read-only bırakın. (Kendiliğinden eklenen Metadata satırı öyle kalsın.)
  5. Sayfanın sonundaki Generate token'a basın, çıkan anahtarı kopyalayıp yukarıdaki kutuya yapıştırın.

Anahtar yalnızca bu tarayıcıda saklanır ve sadece sitenin deposuna erişebilir. Telefonda ya da başka bilgisayarda da aynı anahtarla giriş yapabilirsiniz.
